Random Password Generator (Генератор случайных паролей)

**Автор:** [Ксения Григорьева]  
**Дата создания:** 2026-04-28  
**Язык:** Python 3.x  
**Зависимости:** Только стандартная библиотека (tkinter, random, json, string, datetime, os)

Описание
Графическое приложение для генерации случайных паролей с настраиваемой длиной, выбором типов символов и автоматическим сохранением истории в JSON-файл. Интерфейс построен на `tkinter`, валидация входных параметров реализована на уровне слайдера и программных проверок.

Установка и запуск
1. Убедитесь, что установлен Python 3.6+
2. Клонируйте репозиторий или скачайте файлы
3. Запустите:
   ```bash
   python main.py
